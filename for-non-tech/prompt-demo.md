## Prompt

> **Task:**  
> Analyze these 200 support tickets and reclassify each ticket into the following categories:  
> - Password Reset  
> - Order Status  
> - Refund Request  
> - Technical Issue  
> - Account Deletion  
> - Billing Issues  
> - Feature Requests

---

## Evaluation

### 1. Structure

- **Clear and concise:**  
    The prompt is direct and easy to understand. It clearly states the action (“Analyze and reclassify”) and the input (“200 support tickets”).

- **Specific instruction:**  
    It specifies exactly what categories to use, so the AI knows how to classify the data.

- **No ambiguity:**  
    The task is well-defined without vague terms or unclear expectations.

### 2. Tone

- **Professional and neutral:**  
    The tone is formal but approachable, suitable for a product manager using AI as a tool.

- **Objective:**  
    The prompt stays factual and task-oriented without adding unnecessary fluff or informal language.

### 3. Intent

- **Actionable outcome:**  
    The prompt’s goal is to get a structured reclassification of tickets, which directly helps improve product insights and decision-making.

- **Data-driven:**  
    It aims for clear categorization that can feed into reports or dashboards.

- **Aligned with user role:**  
    Fits the product manager’s responsibility to organize and understand user feedback.
